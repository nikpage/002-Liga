Jak vložit widget na svůj web

Stačí přidat jeden řádek <script> před uzavírací tag </body>:

Základní vložení

<script
  src="https://ligavozic.up.railway.app/widget/liga-widget.js"
  data-server="https://ligavozic.up.railway.app">
</script>

S vlastním nastavením

<script
  src="https://ligavozic.up.railway.app/widget/liga-widget.js"
  data-server="https://ligavozic.up.railway.app"
  data-title="Poradna Liga Vozíčářů"
  data-primary-color="#0066cc"
  data-position="right"
  data-open="false">
</script>

Programatické ovládání

// Otevřít/zavřít widget
LigaWidget.toggle();

Dostupné parametry

Parametr Výchozí Popis
data-server "" URL serveru (povinné)
data-title Otázky a Odpovědi Nadpis v hlavičce widgetu
data-primary-color #007bff Hlavní barva (header, tlačítko, odkazy)
data-position right right nebo left
data-open false Otevřít chat automaticky při načtení
data-z-index 9999 CSS z-index pro widget
